手机改稿指南

马来西亚疯狂季 · 四人小队 · 人不在电脑边时怎么改页面
一句话版：手机浏览器打开 GitHub 仓库里的 index.html → 点铅笔 → 改文字 → 提交。约 1 分钟后自动上线。

改稿六步

1
手机 Safari 打开 github.com，用 Emilynamtan 账号登录。
出门前一定先在手机上登录一次并勾选记住，避免旅途中收不到验证码。
2
打开仓库 github.com/Emilynamtan/Malaysia-trip-2026，点文件名 index.html。
3
点右上角铅笔图标进入编辑（看不到铅笔就点旁边的「⋯」菜单里的 Edit file）。
4
找要改的地方：点地址栏输入关键词（如 吉隆坡两晚），选底部「在此页面上查找」，页面会自动跳到那一段。
5
只改中文和数字 → 滑到页面最底部，点绿色 Commit changes → 再点一次 Commit changes 确认。
6
等约 1 分钟自动上线。打开 malaysia-trip-2026-4.pages.dev 下拉刷新；若还是旧内容，长按刷新按钮用「无痕/清缓存」打开一次。

能改什么、别碰什么

类型举例手机改安全吗
纯文字酒店名、时间、备注、待办事项安全
数字/日期「9/21」「12:00」「RM1050」安全
地址、电话链接地图导航链接里的地址串谨慎，只替换文字部分
颜色、字号、排版<style> 里的 CSS别动
行程/倒计时数据页面最下方 JS 里的日期数组别动，符号错一个整页就空白
安全操作口诀
只在中文字符之间改字，不增加也不删除任何 < > " ' / , 这类符号。
最容易翻车的三件事
① 删掉了多余的引号或尖括号；② 误删了 class="..." 后面的引号；③ 把两行内容粘成一行。
一旦页面空白，立刻按下面的方法回滚。

改坏了怎么恢复

  1. 回到仓库首页，点 Commits（提交记录）。
  2. 找到上一次正常的版本，点进去，再点文件名 index.html 看旧内容。
  3. 点铅笔 → 全选删除 → 把旧内容整段粘回去 → 重新 Commit。
更省事的办法：如果你临时能借到一台电脑（同行朋友的也行），打开 WorkBuddy 跟我说一句「页面改坏了，帮我回滚到上一版」，我一条命令就恢复 —— 项目文件都在 GitHub 上。
